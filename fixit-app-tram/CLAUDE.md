# FixIt

## Context pack
- Vision: Anyone on a team can report a bug in two seconds, and the developer gets the whole story without asking a single question.
- Users: Buyer - Engineering org that self-hosts its tools - Run bug reporting on its own server
Reporter - QA, support, PM - The moment is lost and has to be reproduced, Nobody confirms the fix or tells the reporter
Triager - Five people report the same bug. Triagers merge duplicates by hand.
Fixer - Developer or coding agent - Reports arrive without context.
Admin - Org or instance admin - Screens and logs leak secrets. Security teams block cloud tools.
- Key journey: Get the app -> Capture -> Report -> Triage -> Fix -> Close the loop
